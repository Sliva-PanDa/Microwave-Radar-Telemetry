# СВЧ-Анализатор 24 ГГц (Программно-аппаратный комплекс)

Проект разработан в рамках курсовой работы для исследования радиопрозрачности диэлектриков и затухания электромагнитных волн.

## Технологический стек
*   **Hardware:** ESP32 DevKitC V4, Радар HLK-LD2410C (FMCW, 24 ГГц), Адресная лента WS2812B.
*   **Firmware:** C++ (Arduino IDE) — реализация неблокирующего опроса, фильтрация дистанции (`Spatial Filter`).
*   **Software:** Python 3.12, PyQt5, Pandas, Matplotlib — архитектура MVC, асинхронный GUI, живая симуляция распространения волн.

## Структура проекта
*   `/ESP32_Firmware/` — исходный код для прошивки микроконтроллера.
*   `data_logger.py` — консольный скрипт для связи с ESP32 по COM-порту и проведения натурных экспериментов (запись телеметрии).
*   `main_app.py` — главный модуль графического интерфейса аналитики (Controller / View).
*   `data_engine.py` — модуль работы с базой данных CSV и математической агрегации (Model).
*   `radar_canvas.py` — графический движок для симуляции СВЧ-луча (QPainter).
*   `radar_physics_data.csv` — плоская база данных с результатами натурных экспериментов.
